🦀 Rusty Tools

A local collection of Rust cybersecurity tools. Pick one to get started.

Portofino

Multithreaded TCP port scanner — single host, range, or CIDR block.

PPPP

PickAPeckOfPacketParsers — live packet capture & parsing on a network interface.

OneForTheHoney

Decoy-service honeypot listener — logs every connection attempt against bait ports.

Bunyan

Systemd-journal auth log analyzer — watches sshd & sudo activity for brute-force and compromise patterns.
